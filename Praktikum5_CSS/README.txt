PRAKTIKUM 5 - CSS BOX, POSITIONING, DAN FLEXBOX

1. Ekstrak folder Praktikum5_CSS.
2. Buka folder tersebut melalui VS Code (File > Open Folder).
3. Jalankan file HTML dengan Live Server atau buka langsung di browser.
4. Urutan file:
   - cssbox1.html = Gambar 1 (empat kotak)
   - cssbox2.html = Gambar 3 (susunan lima kotak)
   - cssbox3.html = Gambar 4 (header, kolom, footer)
   - flexbox1.html = Gambar 5 (navbar dan daftar program studi)
   - flexbox2.html = Gambar 6 (header, article, aside, nav, footer)
   - flexbox3.html = Gambar 7 (3 kotak di atas, 5 di bawah)
   - flexbox4.html = Gambar 8(a) dan 8(b)

CATATAN GAMBAR 2:
Untuk bagian modifikasi gambar burung pada cssbox1.html, siapkan empat foto burung
dan simpan di assets/images/ dengan nama burung1.jpg, burung2.jpg, burung3.jpg,
dan burung4.jpg. Ganti isi <main class="browser box1"> pada cssbox1.html menjadi:

<main class="browser box1">
  <img class="foto" src="assets/images/burung1.jpg" alt="Burung 1">
  <img class="foto" src="assets/images/burung2.jpg" alt="Burung 2">
  <img class="foto" src="assets/images/burung3.jpg" alt="Burung 3">
  <img class="foto" src="assets/images/burung4.jpg" alt="Burung 4">
</main>

Untuk logo di Gambar 5, simpan logo STT-NF sebagai assets/images/logonf.png.
Kalau belum punya logo, navbar tetap tampil, hanya gambar logo yang tidak muncul.

PENTING:
- Nama file dan folder harus sama persis dengan yang tertulis di atribut href/src.
- Jangan menghapus folder css karena semua halaman memakai file CSS di dalamnya.
- Sesuaikan foto dan logo dengan aset yang kamu miliki.
